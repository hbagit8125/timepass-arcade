# Screenshots

Captured from a production build in headless Chrome while testing each phase. Dark theme unless noted. Files starting with `m-` or `fit-390-` are phone-sized (390 px wide).

Some shots were taken part-way through a phase, so spacing in the game header may differ slightly from the live site. The `fit-*` and `home2.png` shots show the final Phase 2 layout.
